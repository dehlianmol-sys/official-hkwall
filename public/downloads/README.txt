MAIN APP APK  ->  Supabase Storage bucket "apks", file: hkwallet.apk
Upload it there (Public bucket, up to 50 MB per file). GitHub web
upload stops at 25 MB, so big APKs never go in the repo.

Free recharge APKs (Freecharge / PhonePe / Mobikwik / Paytm) go in
the SAME "apks" bucket: freecharge.apk, phonepe.apk, mobikwik.apk,
paytm.apk.

All download buttons (landing page ke teeno button aur /download
page) read directly from the "apks" bucket.
